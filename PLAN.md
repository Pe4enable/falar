# Português — приложение для изучения европейского португальского

**Концепция:** iOS-приложение для изучения европейского португальского (PT-PT)
по методу Дмитрия Петрова «Полиглот 16 уроков», с расширенным функционалом
и дизайном в стиле Claude.

**Статус:** этап планирования (код пока не пишем).
**Дата ревизии:** 2026-06-11.

---

## 1. Целевая платформа и совместимость

- **Платформа:** нативный iOS, **SwiftUI**.
- **Таргет:** свежая iOS; `deployment target` с запасом (≈ iOS 17),
  чтобы покрыть iPhone 11 и старше.
- **Опорное устройство:** iPhone 11 (чип A13).
  - ⚠️ Нет Apple Intelligence (нужен A17 Pro) → ни одна функция не должна

  - Дизайн лёгкий, без тяжёлых 3D/частиц → плавность на A13.

## 2. Методология (метод Петрова)

Идея: довести **базовые грамматические структуры до автоматизма** до набора
словарного запаса. «Стержень, на который нанизываются бусины».

**Базовая схема глагола** — ядро метода. Система координат:

|              | Прошлое | Настоящее | Будущее |
|--------------|---------|-----------|---------|
| Утверждение  | …       | …         | …       |
| Отрицание    | …       | …         | …       |
| Вопрос       | …       | …         | …       |

Освоив эти ячейки на автомате (× 3 спряжения PT), ученик строит любое простое
предложение.

## 3. Специфика европейского португальского (заложить в данные!)

- 3 спряжения: **-ar / -er / -ir** (falar, comer, partir).
- **tu vs você** (в Португалии «tu» живое) — с урока 1.
- Continuous через **estar a + infinitivo** (*estou a falar*),
  НЕ бразильское *estou falando*.
- Две «быть»: **ser / estar**.
- Озвучка строго **европейским голосом** (Joana/Catarina), не бразильским.
- Орфография с диакритикой: ã, õ, ç, é, ê.

**16 уроков (черновик прогрессии):**
1. Схема глагола, 3 спряжения, três tempos
2. Местоимения и вопросительные слова
3. Ser / Estar, предлоги места, gostar/querer
4. Притяжательные
5. Профессии, этикет, tu/você
6. Степени сравнения, este/esse/aquele
7. Артикли и contrações (do, na, pelo)
8. Предлоги времени, часы
9. Há / there is
10. Предлоги движения, ir a/para
11. Модальные (poder, dever, ter de)
12. Estar a + infinitivo
13. Прилагательные, описание
14. Pretérito Perfeito Composto
15. Повелительное наклонение
16. Идиоматические конструкции

## 4. Карта приложения

- Онбординг (1 раз): приветствие, уровень, цель в день.
- **TabBar:** Дом · Повторение · Профиль.
- **Дом:** карточка «Продолжить», дорожка из 16 уроков (прогресс/замки), streak + цель дня.
- **Урок:** Теория (+ интерактивная таблица глагола) → Практика → Экзамен (10 случайных).
- **Повторение (SRS):** очередь «созревших» карточек из всех пройденных уроков.
- **Профиль:** статистика, карта базовой таблицы, настройки голоса/строгости/напоминаний.

---

## 5. Обучающий цикл (сердце)

Карточка упражнения:
1. Фраза на русском.
2. Пользователь переводит вслух/про себя.
3. «Показать ответ» → перевод PT-PT + автоозвучка.
4. ▶ переслушать, долгий тап — замедленно.
5. Самооценка «Знал / Ошибся» → кормит SRS.

**Режимы упражнений (все 4 — в MVP, в порядке сборки):**
1. 🔤 **Перевод RU→PT** — основной (как Полиглот).
2. 🎧 **Аудирование PT→RU** — слушаешь PT, переводишь на русский.
3. 🧩 **Конструктор** — собрать ответ из плиток-слов (мягкий режим).
4. 🎤 **Произношение** — говоришь вслух, `Speech` (pt-PT) сверяет.
   *Самый рискованный по точности — собираем последним.*

Один режим активен за раз; переключение — настройка (минимализм сохраняем).

## 6. Функционал-отличия от оригинала

- **SRS / интервальные повторения** (FSRS или SM-2) — главное отличие.
- Карта освоения **базовой таблицы** (время × форма × спряжение).
- Streak, цель дня, локальные напоминания (без бэкенда).
- Озвучка офлайн (AVSpeech) + опционально облачная премиум-озвучка с кэшем.
- iCloud-синхронизация прогресса (позже).

Геймификация — умеренная, спокойная (в духе метода: язык = комфорт).
Без «жизней» и стресс-таймеров.

## 7. Технологии

| Функция            | Технология                         | iPhone 11 |
|--------------------|-------------------------------------|-----------|
| Озвучка PT-PT      | AVSpeechSynthesizer (Joana/Catarina)| ✅ офлайн |
| Озвучка премиум    | Azure/Google TTS + кэш аудио        | ✅        |
| Распознавание речи | Speech framework (pt-PT)            | ✅        |
| Локальная БД       | SwiftData                           | ✅        |
| Синхронизация      | CloudKit (iCloud)                   | ✅        |
| Напоминания        | UserNotifications                   | ✅        |

Бэкенда на старте нет — всё локально (дёшево, приватно, офлайн).
Контент уроков — **JSON в бандле**, импорт в SwiftData (правки без пересборки).

## 9a. Монетизация (IAP)

- Первые уроки — **бесплатно** (демонстрируют ценность, как в оригинале).
- **Разблокировка одного урока — $0.99** (для тех, кто хочет один конкретный).
- **Разблокировка всех уроков — $2.99** (основной оффер; дешевле оригинального $4.99).
- Модель: разовые покупки (non-consumable IAP), без подписки.
