# Falar — тренажёр европейского португальского 🇵🇹

**Falar** — бесплатное приложение для изучения **европейского португальского (PT-PT)**
с нуля. Построено на методе «16 уроков»: короткие уроки с теорией и несколькими
режимами практики, экзамены с разблокировкой следующего урока и интервальные
повторения.

🌐 **Живая версия:**
- 🇬🇧 английский интерфейс: **https://falar.dubkov.eu/**
- 🇷🇺 русский интерфейс: **https://falar.dubkov.eu/ru/**

Приложение работает как PWA: открывается в браузере телефона, устанавливается на
домашний экран, большинство режимов работают офлайн. Прогресс хранится в браузере
(localStorage); опционально — синхронизация через небольшой сервер.

## Возможности

- **16 уроков**, 400+ фраз PT-PT с повседневной лексикой Португалии
- **4 режима практики**: Перевод · Аудио (на слух) · Речь (распознавание
  произношения) · Плитки (конструктор фразы из слов)
- **Тренажёр словаря** после теории каждого урока (RU→PT, PT→RU, аудио, речь)
- **Экзамены** с разблокировкой следующего урока (порог 80%)
- **Интервальные повторения** (система Лейтнера: 10 мин → 1 → 3 → 7 → 14 дней)
- **Озвучка и распознавание речи** через Web Speech API (голоса pt-PT)
- **Pro-drop**: ответы с опущенным местоимением-подлежащим засчитываются
- **Два языка интерфейса** — русский и английский — из общего контента
- Светлая и тёмная темы, цель дня и streak

## Структура проекта

| Папка / файл        | Что внутри                                                            |
|---------------------|----------------------------------------------------------------------|
| `web/`              | Веб-приложение (статика: HTML + CSS + JS, без фреймворков)            |
| `content/`          | Учебный контент в JSON (уроки, словари, глоссарий) + генераторы       |
| `server/`           | Опциональный сервис синхронизации прогресса (Node.js + SQLite)        |
| `design/`           | Дизайн-материалы и прототип                                           |
| `*.md`              | Планы, спецификации и документация (RU)                               |

Учебный контент (`web/content.js`) **генерируется** из файлов в `content/` —
руками его не правят.

## Как запустить локально

Самый простой способ — открыть `web/index.html` двойным кликом (контент вшит
в `content.js`). Режим «Речь» требует HTTPS или localhost, поэтому для полного
набора функций запусти локальный сервер:

```bash
npx http-server web -p 8742 -c-1
```

Затем открой http://localhost:8742

### Пересборка контента

После правок уроков в `content/lessons/*.json` или словарей пересобери `content.js`:

```bash
node web/build-content.js      # русская версия
node web/build-en.js           # английская версия (в web/en/)
```

Проверить контент на ошибки:

```bash
node content/validate.js
```

### Сервис синхронизации прогресса (опционально)

Небольшой Node.js-сервис (анонимные аккаунты + код восстановления + опционально
email). Подробности и запуск — в [`server/README.md`](server/README.md).
