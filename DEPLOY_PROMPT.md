# Как развернуть веб-версию Falar на своём сервере

> Готовый текст-инструкция, который можно отдать любому статическому хостингу
> или administrator'у сервера. Файлы приложения лежат в папке `web/`
> (`index.html`, `styles.css`, `app.js`, `content.js` и иконки).

---

Разверни статическое веб-приложение **Falar** (тренажёр
европейского португальского) в **отдельном контейнере** и дай мне ссылку.

## Что это
Чистая статика: HTML + CSS + JS, **без бэкенда, без БД, без секретов, без сборки**.
Весь учебный контент вшит в `content.js` (~90 КБ). Прогресс пользователей хранится
в localStorage их браузеров — на сервере ничего не пишется, контейнер stateless.

Файлы из папки `web/`:
`index.html`, `styles.css`, `app.js`, `content.js` (+ иконки; `README.md` в раздачу не обязателен).
Все пути относительные — можно вешать и на корень поддомена, и на подпуть.

## Требования
1. **Отдельный контейнер** со статическим сервером (`nginx:alpine` или `caddy` —
   на твой вкус / по стандартам сервера). Никакой логики, только раздача файлов.
2. **Обязательно HTTPS** с валидным сертификатом: в приложении есть режим
   распознавания речи (Web Speech API), браузеры дают доступ к микрофону только
   в secure context. Подключи к существующему reverse proxy или выпусти
   Let's Encrypt.
3. **UTF-8**: контент с португальской диакритикой (ã, ç, õ) и кириллицей.
   Для nginx добавь `charset utf-8;`.
4. **Кэширование**: `index.html` и `content.js` — `no-cache` (или max-age≤300),
   я буду обновлять контент заменой файлов; `styles.css`/`app.js` можно кэшировать
   умеренно (max-age≤3600). Агрессивный кэш не ставить.
5. gzip/brotli на текстовые типы — желательно.
6. Файлы выложить **как есть**, ничего не менять. SPA-фоллбек не нужен —
   страница одна.
7. Имя/поддомен на твоё усмотрение (например `falar.<мой-домен>`), мне важна
   только итоговая ссылка.

## Если нет своих стандартов — пример
```yaml
# docker-compose.yml
services:
  falar-web:
    image: nginx:alpine
    container_name: falar-web
    restart: unless-stopped
    volumes:
      - ./falar/web:/usr/share/nginx/html:ro
      - ./falar/nginx.conf:/etc/nginx/conf.d/default.conf:ro
    # порт наружу не нужен, если подключаешь через общий reverse proxy
```
```nginx
# nginx.conf
server {
  listen 80;
  charset utf-8;
  root /usr/share/nginx/html;
  index index.html;
  gzip on;
  gzip_types text/css application/javascript text/html;
  location ~* \.(html)$ { add_header Cache-Control "no-cache"; }
  location = /content.js { add_header Cache-Control "no-cache"; }
}
```

## Приёмка (проверь перед тем как отдать ссылку)
- [ ] Ссылка открывается с телефона; видна заставка **«Falar»** (онбординг, кнопка «Далее»).
- [ ] `content.js` отдаётся со статусом 200 (~90 КБ), в консоли браузера нет ошибок.
- [ ] Сертификат валидный (замок в адресной строке).
- [ ] После прохождения пары карточек и перезагрузки страницы прогресс на месте
      (localStorage работает — значит, домен стабильный, без редиректов туда-сюда).
