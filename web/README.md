# Falar — веб-версия

**Боевые ссылки:**
- 🇬🇧 английская версия (корень): **https://falar.dubkov.eu/**
- 🇷🇺 русская версия: **https://falar.dubkov.eu/ru/**

Английская версия собирается из общего кода: `node web/build-en.js` переводит UI
(словарь `content/i18n/en/ui.json`) и контент (`content/i18n/en/phrases|theory|
vocab|glossary|phrase_gloss.json`) → `web/en/`. Прогресс /en хранится отдельно
(ключ `falar-state-en-v1`).

Полнофункциональная веб-версия приложения: 16 уроков, 388 фраз PT-PT, 4 режима
практики, экзамены, интервальные повторения. Без сервера и без установки —
прогресс хранится в браузере тестера (localStorage).

## Как запустить у себя
Просто открой `index.html` двойным кликом — всё работает локально
(контент вшит в `content.js`).

> Исключение: режим «Речь» (распознавание произношения) требует HTTPS или localhost —
> при открытии файла напрямую браузер не даст доступ к микрофону.
> Остальные 3 режима работают везде.

## Как дать ссылку тестерам (1 минута, бесплатно)
1. Зайди на **https://app.netlify.com/drop** (нужен бесплатный аккаунт).
2. Перетащи мышкой папку `web` целиком в окно браузера.
3. Получишь ссылку вида `https://something.netlify.app` — отправь её тестерам.
   Это HTTPS, значит работает всё, включая режим «Речь».

Альтернативы: Vercel, GitHub Pages, Cloudflare Pages — любой статический хостинг.

## Правила обучения (версия 0.3)
- **Режимы ротируются**: после каждой сессии урок переключается на следующий режим —
  **Перевод → Аудио → Речь → Плитки** → снова Перевод. Можно переключить вручную.
- **Слова**: в каждом уроке после Теории есть тренажёр словаря.
  «Перевод» = с русского на португальский, «Обратно» = с португальского на русский,
  плюс «Аудио» (на слух) и «Речь» (произношение).
- **Плитки бесконечны**: колода урока крутится по кругу, пока сам не выйдешь (×) —
  чтобы можно было набить допуск. Выход не теряет ответы.
- **Допуск к экзамену**: из **последних 100 плиток** урока верных должно быть **≥90**.
  Считаются только ответы в режиме «Плитки». Окно хранится постоянно — выход из
  сессии и из приложения его не сбрасывает. Прогресс — на баре внизу экрана плиток
  и на карточке экзамена; при достижении 90 появляется кнопка «К экзамену».
- **Уроки открываются только экзаменом** предыдущего (≥80%). Все уроки бесплатны.
- **Pro-drop**: подлежащее-местоимение можно опускать (Falo português = Eu falo
  português). В плитках и в режиме «Речь» вариант без местоимения засчитывается
  как правильный; в речи опущенное местоимение зачёркивается серым и не штрафуется.
- **Ротация режимов** после сессии: Перевод → Аудио → Речь → Плитки → по кругу.
- **Плитки бесконечны**: колода урока крутится, пока не выйдешь; считаются
  последние 100 плиток для допуска к экзамену (90/100).
- **Прогресс-бар допуска** — таймлайн последних 100 плиток: красные отметки ошибок
  уезжают влево и выпадают из окна через 100 ответов.
- **Тап по слову** в задании плиток показывает перевод RU→PT (+ озвучка);
  словарь `content/glossary.json` покрывает все слова курса.
- **Плитки можно перетаскивать**: тап = быстрый перенос (как раньше), перетаскивание =
  вставка в нужную позицию, в т.ч. между уже стоящими плитками; плитку из слота
  можно вытащить назад в банк. Двойной тап по сайту больше не зумит.

## Что сказать тестерам
- Открывать лучше на телефоне в **Chrome (Android)** или **Safari (iPhone)** —
  там есть голоса pt-PT и распознавание речи.
- Озвучка использует голоса, установленные в системе. Если португальского голоса
  нет, телефон предложит скачать его в настройках озвучки (iOS: Настройки →
  Универсальный доступ → Устный контент → Голоса → Португальский (Португалия)).
- Прогресс живёт в браузере: не чистить данные сайта, не открывать в инкогнито.
- В Профиле есть тогл «Свободный доступ ко всем урокам» — для быстрого
  просмотра всего курса без сдачи экзаменов.

## Файлы
- `index.html` — оболочка
- `styles.css` — дизайн-токены Claude (светлая + тёмная тема)
- `app.js` — вся логика (экраны, 4 режима, SRS, экзамен, статистика)
- `content.js` — сгенерированный контент; **не править руками**
- `build-content.js` — генератор: `node web/build-content.js` после правок уроков
  в `content/lessons/*.json` или словарей в `content/vocab.json`

## Что собрать с тестеров (вопросы)
1. Понятна ли теория урока без объяснений со стороны?
2. Какой режим практики используешь чаще всего? Какой бесполезен?
3. Озвучка: звучит ли естественно, правильная ли скорость?
4. Длина урока/сессии (10 карточек) — норм или много/мало?
5. Возвращался ли на следующий день? Что вернуло (или не вернуло)?
