# ТЗ на дизайн — приложение для изучения европейского португальского

**Версия:** 1.0 · **Дата:** 2026-06-11
**Назначение:** полное техническое задание для дизайна интерфейса (Claude design language).
Покрывает дизайн-систему, все экраны, все состояния и интеракции.
Связанные документы: [PLAN.md](PLAN.md) (функционал и роадмап).

Рабочее название проекта: **«Falar»** (порт. «говорить») — финальное имя TBD.

# ЧАСТЬ A. ОБЩИЕ ПРИНЦИПЫ

## A1. Платформа и устройства
- iOS, нативный **SwiftUI**.
- Опорные размеры экрана:
  - iPhone 11 / XR — **414 × 896 pt** (база, всё должно идеально влезать).
  - iPhone 15/16 — 393 × 852 pt.
  - SE (2/3) — 375 × 667 pt (минимальная поддержка, проверять переносы).
- Ориентация: только **портрет** (язык учим вертикально, как Полиглот).
- Safe area: учитывать «чёлку»/Dynamic Island и нижний home-indicator.

## A2. Принципы дизайна (Claude language)
1. **Спокойствие.** Тёплая «бумажная» палитра, без кричащих цветов и стресса.
2. **Одна задача на экран.** Минимум элементов в фокусе; всё лишнее убрано.
3. **Воздух.** Щедрые отступы, крупная типографика, дышащие карточки.
4. **Мягкость.** Большие скругления, мягкие тени, плавные переходы.
5. **Тёплый акцент.** Кораллово-терракотовый Claude — только для главного действия.
6. **Честная обратная связь.** Состояния (успех/ошибка) понятны, но не агрессивны.

## B2. Типографика
- **Заголовки (serif):** гуманистический serif в духе Claude (например, *Tiempos / Newsreader / Lora*). Тёплый, книжный.
- **Текст и UI (sans):** чистый grotesque (*SF Pro Text* по умолчанию, либо *Inter*).
- **Контент PT (фразы):** тот же sans, но крупнее и с увеличенным трекингом для читаемости диакритики.

| Стиль            | Шрифт  | Размер/Интерлиньяж | Вес       | Где                         |
|------------------|--------|--------------------|-----------|------------------------------|
| `display`        | serif  | 34 / 40            | Semibold  | Заголовок онбординга         |
| `title-1`        | serif  | 28 / 34            | Semibold  | Заголовок экрана             |
| `title-2`        | serif  | 22 / 28            | Medium    | Заголовок секции / урока     |

- **Dynamic Type:** поддержать (масштабирование шрифтов), верстать на flex-контейнерах.
- Числа в статистике — моноширинные цифры (`monospacedDigit`).

## B3. Сетка и отступы (8pt grid)
- Базовый шаг: **8 pt**. Допустимы 4 pt для мелких деталей.
- Поля экрана (горизонтальные): **20 pt**.
- Вертикальный ритм между блоками: **16 / 24 / 32 pt**.
- Карточки: внутренний паддинг **20 pt**.

## B4. Скругления, тени, границы
- Радиусы: кнопки **14 pt**, карточки **20 pt**, крупные панели **28 pt**, бейджи/пилюли **999 pt** (капсула).
- Тени: мягкие, низкие. `y=4, blur=16, color=#1F1E1B @ 6%`. В тёмной теме теней почти нет — разделяем границами.
- Границы: `1 pt`, `border/subtle`. Только там, где нет тени.

## B5. Иконография
- Стиль: **SF Symbols**, вес `regular`/`medium`, скруглённые.
- Ключевые иконки: дом `house`, повторение `arrow.triangle.2.circlepath`, профиль `person`, звук `speaker.wave.2`, микрофон `mic`, замок `lock.fill`, галочка `checkmark`, серия `flame.fill`, настройки `gearshape`.
- Размер по умолчанию: 24 pt в навигации, 20 pt инлайн.

## B6. Базовые компоненты

### Кнопки
- **Primary (акцентная):** заливка `accent`, текст белый, высота **54 pt**, радиус 14, `callout` semibold. Состояния: normal / pressed (`accent/pressed`, лёгкое сжатие 0.98) / disabled (`text/tertiary` на `surface-sunk`).
- **Secondary:** граница `border/subtle`, текст `text/primary`, прозрачный фон, высота 54.
- **Tertiary / text:** только текст `accent`, без фона.
- **Icon button:** круг 44 pt, фон `surface-sunk`.
- Минимальная зона нажатия — **44 × 44 pt** (везде).

### Карточки
- Фон `surface`, радиус 20, паддинг 20, мягкая тень. Tap — лёгкое сжатие 0.98 + затемнение.

### Поля ввода
- Фон `surface-sunk`, радиус 14, высота 52, плейсхолдер `text/tertiary`. Фокус — рамка `accent` 1.5 pt.

### Прогресс
- **Линейный бар:** высота 8, трек `surface-sunk`, заливка `accent`, скругление капсулой. Анимация заполнения 0.4 s ease-out.
- **Кольцо прогресса:** для цели дня и оценки экзамена.

### Пилюли / бейджи
- Капсула, фон `*/sunk`, текст соответствующего цвета, `caption` medium. Примеры: «-ar», «Урок 3», «🔥 7 дней».

### Сегмент-контрол (выбор режима практики)
- Капсульный контейнер `surface-sunk`, активный сегмент — `surface` с тенью + текст `accent`.

### Модальные / шторки (sheets)
- Bottom sheet, радиус верхних углов 28, ручка-индикатор сверху, фон `surface`. Используется для: выбор голоса, paywall, разбор ошибки.

### Тосты / снэкбары
- Всплывают снизу над TabBar, капсула, авто-скрытие 2.5 s. Для «Сохранено», «Урок открыт».

## B7. Анимация и тактильность
- Длительности: микро **0.15 s**, стандарт **0.3 s**, переходы экранов **0.4 s**. Кривая `ease-out` / spring (response 0.4, damping 0.8).
- Переход карточек практики — горизонтальный слайд + лёгкий fade.
- Появление ответа — раскрытие сверху вниз с fade.
- **Haptics:** правильный ответ — `.success`; ошибка — `.warning`; нажатие кнопки — `.light`; открытие урока/веха — `.medium`.
- Уважать «Reduce Motion» (заменять слайды на fade).

## B8. Состояния (обязательны для каждого списка/данных)
- **Loading:** скелетоны (shimmer) на месте контента, не спиннеры по центру.
- **Empty:** иллюстрация-минимал + текст + действие (напр., «Повторений пока нет — пройди первый урок»).
- **Error:** мягкое сообщение + кнопка «Повторить».
- **Offline:** баннер сверху «Нет сети — озвучка работает офлайн».

## B9. Доступность
- Контраст текста ≥ 4.5:1 (проверить `text/secondary` на `bg/canvas`).
- Поддержка Dynamic Type вплоть до XXL без обрезаний.
- VoiceOver: подписи ко всем кнопкам/иконкам; фраза и её перевод — отдельные элементы.
- Touch targets ≥ 44 pt.
- Не передавать смысл только цветом (правильно/ошибка — цвет + иконка).

# ЧАСТЬ D. ПОСТРАНИЧНАЯ СПЕЦИФИКАЦИЯ

&gt; Формат каждого экрана: **Назначение · Макет · Элементы · Состояния · Интеракции · Данные**.

## D0. Онбординг (первый запуск, 3–4 экрана, свайп)

**Назначение:** объяснить метод и собрать минимум настроек.
**Макет:** полноэкранные слайды, индикатор-точки снизу, кнопка «Далее» (primary).
**Экраны:**
1. *Приветствие* — крупный `display` заголовок, короткий подтекст про метод Петрова, иллюстрация-минимал.
2. *Как это работает* — 3 пункта: «Учим структуры до автоматизма», «Говорим вслух», «5 минут в день».
3. *Цель в день* — выбор: 10 / 20 / 30 карточек (сегмент-контрол), пояснение.
4. *Готово* — «Начать с Урока 1» (primary).
**Состояния:** последний слайд — primary вместо «Далее».
**Интеракции:** свайп между слайдами; «Пропустить» (tertiary, вверху справа).
**Данные:** сохраняет `dailyGoal`, флаг `onboardingDone`.

## D1. Дом (Home)

**Назначение:** точка входа, продолжение обучения, обзор пути.
**Макет (сверху вниз):**
1. **Шапка:** приветствие `title-1` («Olá!»), справа — бейдж streak «🔥 N».
2. **Кольцо цели дня:** прогресс «12/20 карточек сегодня», под ним подпись.
3. **Карточка «Продолжить»** (акцентная, крупная): динамический заголовок —
   - если есть повторения → «Повторить N карточек»,
   - иначе → «Урок K · Практика». Кнопка-стрелка справа.
4. **Дорожка 16 уроков** — вертикальный список карточек уроков:
   - Пройденный: галочка `success`, прогресс 100%.
   - Текущий: акцентная рамка, прогресс-бар, подпись «Продолжить».
   - Заблокированный: иконка `lock`, приглушён, тап → Paywall.
   - Каждая карточка: номер урока (бейдж), название (`title-2`), краткая тема (`caption`), мини-прогресс.
**Состояния:** Loading (скелетоны карточек); первый запуск (только Урок 1 активен).
**Интеракции:** тап по «Продолжить» → нужный экран; тап по уроку → LessonDetail; тап по замку → Paywall; pull-to-refresh не нужен (данные локальны).
**Данные:** список уроков, прогресс, streak, цель/выполнено за день, SRS-очередь.

## D2. Урок — обзор (LessonDetail)

**Назначение:** вход в конкретный урок.
**Макет:** шапка с номером и названием урока, тематические пилюли (напр., «ser/estar», «-ar»). Три крупные кнопки-карточки:
- **Теория** (иконка книги) — статус «прочитано/нет».
- **Практика** (иконка карточек) — прогресс «18/40 фраз».
- **Экзамен** (иконка медали) — заблокирован, пока практика &lt; порога; иначе лучший результат «%».
**Состояния:** экзамен заблокирован (приглушён + подпись «Пройди практику на 80%»).
**Интеракции:** назад — стрелка/свайп; тап по карточке → раздел.
**Данные:** прогресс урока по разделам, лучший результат экзамена.

## D3. Теория (Theory)

**Назначение:** короткое объяснение структуры урока.
**Макет:** скроллируемый контент:
- Заголовок темы (`title-1`).
- Абзацы объяснения (`body`), компактно.
- **Интерактивная таблица глагола** (ядро урока 1 и опорная далее):
  сетка 3×3 (формы × времена) для выбранного спряжения; над таблицей —
  сегмент-контрол спряжения (-ar / -er / -ir).
  - Ячейка: пример («falo», «não falo»…). **Тап по ячейке → озвучка PT + подсветка**.
- Примеры-фразы с кнопкой ▶ озвучки.
**Состояния:** озвучка играет — иконка `speaker.wave.2` анимируется.
**Интеракции:** тап по ячейке/фразе → звук; кнопка внизу «К практике» (primary, sticky).
**Данные:** теория-текст, таблица спряжений, аудио.

## D4. Практика — сессия (PracticeSession) ★ ядро приложения

**Назначение:** прохождение карточек в выбранном режиме.
**Общий каркас экрана:**
- **Топ-бар:** «×» (выйти), прогресс-бар сессии, счётчик «7/20».
- **Переключатель режима** (опционально, сегмент-контрол под топ-баром):
  Перевод · Аудио · Конструктор · Произношение. По умолчанию — выбранный в настройках; можно скрыть для чистоты.
- **Зона карточки** (центр).
- **Зона действий** (низ).

Карточка проходит две фазы: **Вопрос** → **Ответ** (раскрывается).

### Режим 1 — Перевод RU→PT (основной)
- *Вопрос:* фраза на русском (`phrase-ru`) по центру; подсказка «Переведите вслух».
  Низ: кнопка **«Показать ответ»** (primary).
- *Ответ:* появляется фраза PT (`phrase-pt`) + автоозвучка; под ней — RU для сверки.
  Кнопка ▶ переслушать, кнопка «медленно» (0.5×).
  Низ: две кнопки — **«Ошибся»** (secondary, иконка) / **«Знал»** (primary, success-окрашенная).

### Режим 2 — Аудирование PT→RU
- *Вопрос:* большая круглая кнопка ▶ (играет фразу PT, без текста). Можно переслушать.
  Низ: «Показать ответ».
- *Ответ:* текст PT + перевод RU. Самооценка «Ошибся / Знал».

### Режим 3 — Конструктор из слов
- *Вопрос:* фраза RU сверху. Ниже — «слот-зона» (пустая строка ответа) и «банк»
  плиток-слов PT (вперемешку, + лишние дистракторы).
- Тап по плитке → она перемещается в слот; тап в слоте → возврат в банк.
- Кнопка **«Проверить»** (primary, активна когда слот непуст).
- *Ответ:* подсветка верно/неверно по словам (success/error), правильный вариант + озвучка. Далее «Дальше».

### Режим 4 — Произношение (микрофон)
- *Вопрос:* фраза PT показана + озвучена эталоном. Большая кнопка **🎤 «Говорите»**.
- При записи — анимация уровня звука (волна), live-транскрипция.
- *Ответ:* сравнение распознанного с эталоном — слова подсвечены (совпало `success` / нет `error`), оценка «N% совпадение». Кнопки «Ещё раз» / «Дальше».
- ⚠️ Требует разрешения на микрофон и распознавание речи (запрос при первом входе, экран-объяснение).

**Состояния (общие):**
- Right/Wrong feedback: цвет + иконка + haptic.
- Озвучка играет / загружается (для облачной).
- Нет разрешения на микрофон (режим 4) → плашка с кнопкой «Разрешить».
- Конец сессии → экран результатов (D5).
**Интеракции:** «×» → подтверждение выхода (sheet «Прервать сессию?»); свайп влево — следующая карточка после ответа.
**Данные:** очередь карточек сессии, режим, аудио, результаты ответов (для SRS).

## D5. Результаты сессии

**Назначение:** итог практики, мотивация.
**Макет:** крупная галочка/иллюстрация, «Готово!», статистика: верно N из M, +прогресс урока, обновление streak/цели дня. Кнопки: «Продолжить урок» / «На главную».
