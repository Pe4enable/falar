# Схема данных контента (JSON)

Каждый урок — отдельный файл `content/lessons/lessonNN.json`.
Эта же структура → модели SwiftData в коде (трек 2). Поля помеченные `?` — необязательные.

## Урок (Lesson)
```jsonc
{
  "id": 1,                       // стабильный числовой id
  "number": 1,                   // порядковый номер (для отображения "Урок 01")
  "title": "Глагол falar — настоящее -ar",
  "topic": "Спряжение -ar, утверждение / отрицание / вопрос",
  "tags": ["-ar", "presente"],   // пилюли в шапке урока
  "free": true,                  // бесплатный (первые 2 урока)
  "theory": {
    "intro": "Короткий абзац-объяснение…",
    "blocks": [                  // последовательность блоков теории
      { "type": "text", "content": "Абзац…" },
      { "type": "note", "content": "Подсказка про EP-норму…" }
    ]
  },
  "verbTable": {                 // опорная таблица урока (показывается в теории)
    "verb": "falar",
    "translation": "говорить",
    "conjugation": "ar",         // ar | er | ir | irregular
    "schema": {                  // 3×3 «база» — представительная форма (eu)
      "present":  { "affirm": "falo",       "negate": "não falo",       "question": "falo?" },
      "past":     { "affirm": "falei",      "negate": "não falei",      "question": "falei?" },
      "future":   { "affirm": "vou falar",  "negate": "não vou falar",  "question": "vou falar?" }
    },
    "presentFull": {             // полное спряжение настоящего (для теории)
      "eu": "falo", "tu": "falas", "ele": "fala", "nos": "falamos", "eles": "falam"
    }
  },
  "phrases": [ /* см. Phrase */ ],
  "exam": {
    "count": 10,                 // сколько случайных заданий
    "passThreshold": 0.8         // порог прохождения (80%)
  }
}
```

## Фраза (Phrase)
```jsonc
{
  "id": "l1-001",                // уникальный: lessonN-номер
  "ru": "Я говорю по-португальски.",
  "pt": "Eu falo português.",
  "literal": null,               // ? дословная подсказка, если полезно
  "tense": "present",            // present | past | future | continuous | imperfect | mixed
  "form": "affirm",              // affirm | negate | question
  "conjugation": "ar",           // ar | er | ir | irregular | mixed | n/a
  "verb": "falar",               // ? основной глагол фразы (для карты таблицы)
  "tags": ["presente"],          // ? доп. метки ("chunk" = устойчивая формула, учится целиком)
  "distractors": ["falas", "inglês"], // 1–3 лишних слова для режима «Конструктор»
  "audio": null                  // ? имя аудиофайла; отсутствие поля = null (генерируем позже)
}
```

## Разбиение фраз на плитки (режим «Конструктор»)
- **Плитки** = поле `pt` без конечной пунктуации (`.`, `?`, `!`), разбитое по пробелам.
  Запятые внутри фразы убираются при разбиении.
- Слова с дефисом (`pequeno-almoço`, `fim de semana` — без дефиса = 3 плитки) — одна плитка, если написаны слитно через дефис.
- Повторы слов допустимы (в вопросах «O que é que…» слово *que* встречается дважды —
  в банке будет две одинаковые плитки).
- **Дистракторы** добавляются в банк плиток; они не должны совпадать ни с одним словом фразы
  (валидатор `content/validate.js` это проверяет).
- Регистр: MVP показывает плитки как есть (заглавная буква первого слова — допустимая подсказка;
  улучшение — приводить к нижнему регистру, кроме имён собственных).
- Длина фразы: **2–8 плиток** (комфортно для экрана 393–414 pt).

## Словарь урока (vocab.json)
Слова для тренажёра «Слова» хранятся отдельно — в `content/vocab.json`,
ключ = id урока, значение = массив `{ "pt": "...", "ru": "..." }`.
При сборке (`node web/build-content.js`) словарь вливается в урок как `vocab`,
каждому слову присваивается id `l<урок>v<номер>`. Допустимы словосочетания
(«casa de banho»). Слова не участвуют в SRS-повторениях фраз и в допуске
к экзамену — они только для тренажёра и цели дня.

## Соглашения
- **id фраз:** `l<номер_урока>-<NNN>` (l1-001, l1-002…). Стабильны — на них завязан прогресс/SRS.
- **Аудио:** имя файла = `<id>.mp3`, кладётся в `content/audio/`. Пока `null` — генерируем позже.
- **Диакритика:** хранить как есть в UTF-8 (ã, ç, õ…). Файлы сохранять в UTF-8 без BOM.
- **Карта базовой таблицы (D9):** считается по полям `tense` × `form` × `conjugation` фраз.
- **Экзамен:** задания берутся случайно из `phrases` урока.
