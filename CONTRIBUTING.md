# Как внести вклад в Falar

Спасибо, что хотите помочь! Проект открыт для участия — от исправления опечаток
в переводах до новых режимов практики.

## С чего начать

1. **Fork** репозитория и клонируйте свой форк.
2. Создайте ветку под изменение: `git checkout -b fix/opisanie-izmeneniya`.
3. Внесите правки (см. разделы ниже).
4. Проверьте, что всё работает (запуск и валидация — ниже).
5. Закоммитьте и запушьте в свой форк, затем откройте **Pull Request**.

Небольшие правки (опечатки, одна фраза) можно предложить прямо через веб-интерфейс
GitHub без локального клона.

## Запуск и проверка

```bash
# Локальный запуск веб-приложения
npx http-server web -p 8742 -c-1      # → http://localhost:8742

# Проверка контента на ошибки (обязательно перед PR, если меняли контент)
node content/validate.js
```

Для JS-зависимостей сервиса прогресса: `cd server && npm install`.

## Контент (уроки, фразы, словари)

Это главная ценность проекта. **Не редактируйте `web/content.js` напрямую** — он
генерируется.

- Уроки и фразы: `content/lessons/lesson01–16.json`
- Словари и глоссарий: `content/vocab.json`, `content/glossary.json`, и др.
- Переводы интерфейса: `content/i18n/`
- Схема данных и правила: `content/SCHEMA.md`

После правок пересоберите и проверьте:

```bash
node web/build-content.js
node web/build-en.js
node content/validate.js
```

Португальский — **европейский (PT-PT)**, не бразильский. Если вы носитель или
уверенно владеете PT-PT, вычитка фраз особенно ценна.

## Код веб-приложения

Чистый HTML/CSS/JS без фреймворков и сборщиков:

- `web/app.js` — вся логика (экраны, режимы практики, SRS, экзамены)
- `web/styles.css` — стили (дизайн-токены, светлая + тёмная тема)
- `web/index.html` — оболочка

Старайтесь держать стиль кода единообразным с окружающим.

## Pull Request

- Один PR — одно логическое изменение.
- Опишите, **что** и **зачем** меняли.
- Если меняли контент — подтвердите, что `node content/validate.js` проходит чисто.
- Для заметных изменений в UX приложите скриншот.

## Вопросы и идеи

Открывайте [issue](../../issues) — обсудим. Спасибо за вклад! 🙏
